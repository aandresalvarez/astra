## Isolation

The native test uses a separate development bundle
`com.coral.ASTRA.sshqa.20261025`, a separate `AstraDev` store under
`ASTRA SSH QA 20261025`, and synthetic workspaces under
`/private/tmp/astra-pr540-ssh-qa/Workspaces`. A real OpenSSH server listens only
on `127.0.0.1:22440`, with temporary client/host keys, pinned host verification,
password authentication disabled, and an isolated remote home. Production
ASTRA data and defaults are not used. Existing isolated provider profiles are
reused in place; credentials are not copied.

## Deliberate safety limit

SSH process groups cannot contain arbitrary detached or externally submitted
work. A reported job result or cancellation therefore never proves all tools
stopped and never releases the persistent owner's reservation. Approval, Retry,
or app restart cannot override that boundary. Runtimes without live permission
callbacks may remain blocked after an Ask checkpoint for this reason.
