## Isolation

`com.coral.ASTRA.sshqa.20261025`, a separate `AstraDev` store under
`ASTRA SSH QA 20261025`, and synthetic workspaces under
`/private/tmp/astra-pr540-ssh-qa/Workspaces`. A real OpenSSH server listens only

password authentication disabled, and an isolated remote home. Production
ASTRA data and defaults are not used. Existing isolated provider profiles are
reused in place; credentials are not copied.

## Defects found in the native flow

- Packaged helper location and exact sandbox read grants differed from the
  development layout; bundle-aware discovery and packaging now agree.
- Cursor's `shellToolCall` needed the same permission classification as Bash.
- OpenSSH splits UserKnownHostsFile values after shell parsing. A shared quoting
  function now preserves spaces and quotes for launch and later observations.
- Python 3.9 on macOS has process-relative `time.monotonic()` epochs. Sampling and
  supervision now use an explicitly versioned POSIX CLOCK_MONOTONIC domain;
  missing or incompatible persisted domains cannot launch or refill a deadline.
- The output scroll view collapsed visually. It now has a bounded visible height.
  A secondary-review finding also added per-request/task/job identity so delayed
  replies cannot overwrite a newer selection or show another task's output.

## Deliberate safety limit

SSH process groups cannot contain arbitrary detached or externally submitted
work. A reported job result or cancellation therefore never proves all tools
stopped and never releases the persistent owner's reservation. Approval, Retry,
or app restart cannot override that boundary. Runtimes without live permission
callbacks may remain blocked after an Ask checkpoint for this reason.
